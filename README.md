# Personal Portfolio

Single-page portfolio for Hussain Nasir — Next.js, TypeScript, Tailwind CSS, Framer Motion, Lenis, and GSAP.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

All site copy lives in `data/content.ts`. Replace `public/resume.pdf` with your resume.
